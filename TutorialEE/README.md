# Estimating Equations Essentials 

### Paul N Zivich, Rachael K Ross, Stephen R Cole, Ashley I Naimi, Jessie K Edwards

-----

The folder contains code to replicate the analyses described in the correspond paper.

-----

## File Manifesto

`figures.py`
- Recreates the figures in the corresponding publication

`solve_ee.py`
- Computes the example of estimating equations described in the paper using Python

`solve_ee.R`
- Computes the example of estimating equations described in the paper using R

`solve_ee.sas`
- Computes the example of estimating equations described in the paper using SAS

-----

## Versioning

Python (3.13.7)
- `numpy` (2.3.5), `pandas` (2.3.3), `scipy` (1.16.3), `delicatessen` (4.3)
- Figures additionally require `matplotlib` and `seaborn`

R (4.5.2)
- `tidyverse` (2.0.0), `numDeriv` (2016.8.1.1), `rootSolve` (1.8.2.4), `geex` (1.1.1)
