# Combining Randomized and Observational Data: The Case of Postnatal Prophylaxis Against HIV

## Yin DE, Zivich PN, Giganti MJ, Wu D, Edwards JK, Cole SR

--------------------------------

## File Manifesto

`dgm.csv`
- Functions relevant to the data generating mechanism for the simulations

`efuncs.py`
- Estimating functions used in the simulation study

`power_main.py`
- Main simulation experiments reported in the paper

`power_obs.py`
- Simulation experiment for how precision changes as a function of external control size

`power_ratio.py`
- Simulation experiment for how precision changes as a function of trial size and randomization scheme
